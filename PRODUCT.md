# Folio

A local macOS reading library for X Articles. The user has explicitly chosen a restrained Cursor-like workspace with a Notion-like article table. Import, offline reading, ratings, topics and Word-style selection annotations work without API keys. Optional direct OpenAI, Anthropic or DeepSeek analysis produces editable topic notes and cards. Markdown files remain usable in Obsidian and coding agents. Open With menu opens the same library, not an export copy.

Chinese UI with plain short action labels. No weekly recommendation dashboard, no marketing hero, no invented scores, no automatic source deletion. Old articles are not assumed obsolete. User annotations belong in the same Markdown as the source; AI outputs live separately.

Platform: Electron desktop, macOS first. Surface modes: Operate for library/settings, Read for article. Audience: individual collecting articles. All choices derive from the completed user interview in this chat. Product name Folio is the product name.
